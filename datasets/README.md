# Datasets overview

This repository does not ship live data. Instead, it documents a neutral, reusable schema that researchers can adapt for public datasets, job board exports, or surveys. The goal is to promote transparent field definitions, reproducible analysis, and clear provenance for any employment data collected.

## Dataset philosophy
- Use explicit field definitions and controlled vocabularies.
- Keep personally identifiable information (PII) out of datasets by default.
- Store source URLs and timestamps to make entries auditable.
- Separate raw records from curated or enriched datasets.

## Sample schema
A sample schema is provided in [sample_jobs_schema.json](sample_jobs_schema.json).
